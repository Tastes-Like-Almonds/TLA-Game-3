### Sound Design

**NOTE:** For sound design, use exclusively [Jummbox](https://jummb.us/) and/or [jsfxr](https://sfxr.me/) for sounds. You can use audacity to tweak sounds if needed, though its best to not *record* sounds directly (to better fit the theme)

Also, sounds may need to be remade as time goes on. Quality SFX is more important for this game than the last, so spend some extra time if needed to get feedback / improve sounds.

**High Priority (<1 week of time from first meeting)**
- Scrape sound (0.5s-5s)
	- It should NOT fade in/out, just be a persistent scrape sound. For context, this plays and auto-fades when the sword is sliding across the ground.
	- It should loop cleanly
- Sword swing sound (0.5-5s)
	- Similarly to scrape, it should be a constant sound and not fade or change dramatically over time
	- It should sound like wind/a sword swinging in mid-air
	- It should loop cleanly
- Zipline ride sound (0.5-5s)
	- Might need to get creative, but make it a constant sound like the past two.
- Ground slide sound (0.5-5s)
	- You can probably infer from the name, but make it a constant sound like the others.
	- This is played when the player is sliding on the ground
- Airtime sound (0.5-5s)
	- Plays when the player is flying through the air. It should just sound like wind, and be constant like the others.
- Pickup sound
	- Sword pickup sound (<0.5s)
	- Staff pickup sound (<0.5s)

**Medium Priority**
- Sword slash sound
	- <0.5s
		- Played when it hits something living, so make it a satisfying impact sound.

### Art

**High Priority (<1 week of time from first meeting)**
- Palate - First area
	- Select 12-16 colors for the first area, or less if possible. This should be a hard limit of colors, as we want to push the retro theming of this game more this year.
	- Make sure you can distinguish between the player and environment
	- A background is needed, too. Make sure the colors allow for this.
	- For the first area, imagine a dungeon environment with saturated bricks (the color of them themselves is up to you, but make it interesting).
	- The player isn't included in the color palate, but make sure they player goes with it.
- General graphics notes
	- 16x16 is the target for the game. This can be changed if needed, but try it out for a while and see what we can get.
		- This is the size of each tile, the size of the player, and their weapon.
			- The weapon might be bigger, but we'll get to that.
- Character concept
	- Ideally a square character (It's better for gameplay) 
	- Consult with Anton about the story of the character, and work to create a character.
	- Remember that cosmetics will also exist in the game, though animations for the character are not needed as much.

### Art - Environment

**NOTE:** When I say "Terrain", I mean the circle thing you did with the bricks. I'll use this term from now on to clarify how it should be made.

**High Priority**
- Add bricks fading out on the edge tiles
- "Snowy Brick" terrain. Copy paste bricks, just add some snow on top.
- 3 Decoration tiles for the inside of the bricks
	- Make them very subtle
	- They can be anything, as long as they give some texture to the walls
	- You can add more, just keep it organized as you won't be able to move tiles around later
- Tiled stone terrain. Similar to bricks, but square.

**Medium Priority**
- Add 3-5 Decorations to be placed on the ground/ceiling. Make it fit a dungeon-like theme. You could add debris, broken swords, skulls, etc. 
- Lantern sprites **SAVE THESE IN SEPARATE FILES**
	- Ceiling lantern 16x16. Make it touch the top of the sprite but not take up all the room. If you want to add a 2-3 frame animation, that would be cool. Not necessary, but I highly recommend.
	- Ground lantern 16x16, both on and off versions
	- Tall ground lantern 16x32, both on and off versions. This one needs a "turning on" animation, and an animation while lite.
