## Github Issues

Use Github Issues whenever applicable. If you have a bug, report it through github. This allows for clear management of every problem and also allows for more OGPC documentation. **Do it!**

Also use github issues for suggestions, **but do not suggest features/areas/content unless there is a very good reason for it.** Instead, make suggestions for the already existing mechanics, for instance "Increase player gravity" or "Change the  \_\_\_ part of level \_\_\_" ****

**If you or someone you know is playtesting, create issues for every bug you find.** But make sure that an issue is not already created regarding this. Give it a clear, concise title and exact reproduction steps in the issue. Follow this template, should you need:

**The issue:** Provide a brief overview of the problem

**Reproduction Steps:** Give exact steps on how to replicate the bug, and provide screenshots if possible.

**Possible solution (If applicable):** If you are familiar with the system, write where the problem may be located.
