## Naming

- Files should named in`snake_case`
- Folders should be in `PascalCase`

## Structure

- Each scene should be properly sorted under res//Scenes
- Any script that belongs to a scene should be named corresponding to the node it is attached to, and under res//Scripts following the same directory path as the scene. 
	- For instance, `Scenes/Player/player.tscn` should correspond to `Scripts/Player/player.gd`
